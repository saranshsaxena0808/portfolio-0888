# Saransh Saxena — International Analyst Portfolio

Standalone international-facing portfolio. No India/International toggle.


## Features
- Dark editorial / next-generation visual design
- Animated hero orb, orbiting elements, moving ticker and project visuals
- Scroll reveal transitions and responsive mobile navigation
- Interactive project case-study modals
- About, skills, approach, experience and contact sections
- Resume PDF included
- Reduced-motion accessibility support

## Run locally
1. Install Node.js LTS.
2. Extract this ZIP and open the project directory in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the localhost address printed by Vite.

## Build for deployment
```bash
npm run build
npm run preview
```
Deploy the `dist` folder to Vercel or another static host.


## Content note
Project summaries and achievement metrics are based on the CV/project context supplied. Case-study popups describe project scope and exploratory areas; they do not invent outcomes. Update contact email or public links if needed.
